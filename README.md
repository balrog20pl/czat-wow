# Czat WoW

Aplikacja KO.Media do tłumaczenia czatu w World of Warcraft: Forever. Wymaga osobnego dodatku Czat WoW.

A KO.Media desktop companion for Polish–English text chat translation in World of Warcraft: Forever. The Czat WoW addon is required.
